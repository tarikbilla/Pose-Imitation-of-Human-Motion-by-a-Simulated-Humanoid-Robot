# Laboratory / NVIDIA variant of requirements.txt. Install this INSTEAD of
# requirements.txt, never alongside it: onnxruntime, onnxruntime-directml and
# onnxruntime-gpu all provide the same module name and silently replace each
# other.
#
# The onnxruntime-gpu build must match the installed CUDA and cuDNN version.
# A mismatch shows up only as CUDAExecutionProvider missing from
# ort.get_available_providers(), with no further explanation.
#
# rtmlib is installed separately with --no-deps by tools/setup_env.py.
# Installing it normally pulls in plain `onnxruntime`, which replaces the GPU
# build and removes CUDAExecutionProvider. The pipeline then runs on CPU with
# no error, roughly 8x slower.
#
